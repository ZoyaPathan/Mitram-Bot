# MITRAM Bot

MITRAM is an elderly care and assistance robot designed to support elderly individuals with safety, monitoring, communication, navigation, and emergency assistance.

## Current Development Focus

This repository currently focuses on the software/backend of the physical MITRAM bot.

The mobile application will be developed separately at a later stage.

## Technology

- Python
- FastAPI
- SQLAlchemy
- SQLite
- REST API
- WebSocket communication
- AI and voice processing
- Computer vision
